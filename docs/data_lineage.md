## 三组守恒关系

```text
43,653,625 已知记录 = 27,792,348 相关性排除 + 1,048,465 质量剔除 + 14,812,812 保留处理
14,812,812 保留处理 = 14,420,658 字段方案 + 392,154 复杂语义来源
 392,154 语义来源 =    388,348 不同内容代表 + 3,806 重复来源
```

388,348只表示语义通道去重后的代表数量。代表推理完成后，逐来源核对并回填到392,154条复杂来源，再与14,420,658条字段方案记录合并。最终14,812,812条台账按EXTRACTED 6,300,941、NO_EVENT 2,332,837、REVIEW 6,179,034分别保留状态。

03–05的排除记录采用合并后的最终对账量，不将27,792,348条虚拆到单个步骤。方案数、文件数、记录数、提及数、画像数和事件观察数是不同单位。一条记录可能包含多个主体提及、一个主体可能关联多个事件；相关数量不能互相相减或相加当成同一个总体。
