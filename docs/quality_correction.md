# 占位行质量更正

2026-11-24审查发现，原始下载CSV的一组占位行主导了此前73.0%的精确重复比例。这些行不是有效业务内容，现已从处理结果中移出，单列质量剔除台账。当前页面和README采用更正版汇总。

## 数据与验收

| 去向 | 数量 |
| --- | ---: |
| 原始解析计数，包含随后剔除的内容 | 43,653,625 |
| 相关性排除 | 27,792,348 |
| 质量剔除：仅含表头标签的占位行 | 1,048,465 |
| 更正后保留处理 | 14,812,812 |
| 其中字段方案通道，含待复核 | 14,420,658 |
| 其中复杂语义来源 | 392,154 |
| 复杂语义内容代表 | 388,348 |
| 复杂语义精确重复来源 | 3,806 |

三项守恒关系：

```text
43,653,625 = 27,792,348 + 1,048,465 + 14,812,812
14,812,812 = 14,420,658 + 392,154
392,154 = 388,348 + 3,806
```

精确重复比例为3,806 / 392,154 = 0.970537%，页面显示0.97%。它只描述清洗后复杂语义通道，不是全批重复率、语义准确率或运行时间降幅。

原文件哈希已核对。占位内容为“序号为空、案卷编号为字段名自身、问题详细描述为空”，CSV记录112至1,048,576共1,048,465条。不是解析器生成了这些行；原读取器只跳过全空行或完整重复表头，未识别这种部分表头标签占位。

更正版逐条台账回读结果为EXTRACTED 6,300,941、NO_EVENT 2,332,837、REVIEW 6,179,034，合计14,812,812。已通过来源记录ID关联检查，质量剔除行对应的主体提及和事件来源均为0，因此5,202,714个画像、5,968,620条事件观察、6,331,400条事件来源无需重算。

## 复现与文件

使用[质量更正脚本](../scripts/correct_placeholder_rows.py)，在私有环境创建独立导出：

```text
python scripts/correct_placeholder_rows.py --run-dir /private/completed_run --output-dir /private/new_quality_revision
```

脚本固定已审查的源文件哈希、字段模式和连续记录范围；源内容变化、存在主体或事件来源、数量不守恒时中止。目标必须是运行目录以外的新空目录。

- `05_quality/placeholder_records.parquet`：被质量剔除的完整来源台账，附质量原因。
- `08_results/record_ledger.parquet`：更正后的14,812,812条处理台账。
- `correction.json`：更正依据、状态数量及守恒验收。
- 其他未受影响的08导出链接到原结果，不复制或覆盖它们。

原始附件、原运行目录、推理检查点和历史执行进度保留。原05原值文件和06分组索引是历史证据，未经筛除的旧文件不能作为更正版数量依据。新数量以更正版逐条台账和`correction.json`为准。

时间图继续保留更正前388,349个代表的实际观测，并明确标注历史口径。不能将每个历史观测点机械减一，因为没有逐时验证该占位代表何时完成。当前业务代表数为388,348。

[公开更正汇总](../showcase/assets/quality-correction.json)只含统计和相对文件索引，不包含原始业务记录、企业标识或私有路径。
